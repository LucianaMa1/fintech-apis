Fintech API catalogue

Find the right fintech API for products, workflows, and infra

Inspired by public-apis, rebuilt for fintech with filters for regulation, jurisdiction, data sensitivity, and pricing.

Why this exists

General API lists flatten fintech into one category. This catalogue keeps the browseability of public-apis but adds the metadata fintech teams actually need to compare providers.

MVP scope

Searchable directory, fintech-specific filters, seed dataset, and a repository structure that can grow into a richer machine-readable catalogue.

Data model

Every record carries function, regulatory model, regions, sensitivity, pricing, integration mode, and basic access metadata like auth, HTTPS, and sandbox.
